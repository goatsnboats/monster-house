# Build results

> **Status:** Current · **Updated:** 2026-11-25

Evidence that each build step does what the [Stage 0 plan](../stage-0-plan.md) says it
should: pictures of it working, the tests that check it, and what is still unchecked.
One folder per step, named after it (`stage-0-step-3/`), with a `README.md`, a
`figures/` folder, and the raw numbers where there are any. Trade-study evidence stays
with its study in [trades/results/](../trades/results/).

Figures are made by a script in `tools/results/` from the real code, so they can be
made again after a change. Each report says how.
