# themes/ — per-holiday personality as data

One folder per theme (`halloween/`, `christmas/`, ...) holding `settings.yaml`
(timings, clip pools, show hours), eye art, audio and lip sequences.
See `docs/architecture.md` §9.

**Status:** `halloween/settings.yaml` exists (ICD-005's example values); the eye renderer reads its colors and blink timing. Clips, audio and eye art come with the brain (Step 4) and content (Step 7).
