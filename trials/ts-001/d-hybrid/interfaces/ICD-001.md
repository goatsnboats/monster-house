# ICD-001 — Monster brain → eye renderers: look points

> **Status:** Draft · **Requirements:** BRN-003, EYE-003

The brain tells both eyes where to look. Each eye computes its own angle from its own
window position (architecture §2), so the brain sends one point, not two angles.

```yaml
id: ICD-001
ends: {from: monster-brain.mqtt, to: eye-renderer.mqtt}
medium: Wi-Fi, MQTT via Mosquitto
messages:
  - topic: monster/eyes/look
    qos: 0
    retain: false
    rate_hz: 10
    payload_schema:
      oneOf:
        - type: object
          required: [x, y, z]
          properties: {x: {type: number}, y: {type: number}, z: {type: number}}
        - type: object
          required: [mode]
          properties: {mode: {enum: [idle]}}
    examples:
      - {x: 1.2, y: 3.5, z: 1.0}
      - {mode: idle}
```

**Units:** meters, in house coordinates (architecture §3b).

**Failure behavior:** the eye ignores a malformed payload and keeps its last target. If no
message arrives for 2 s, the eye wanders on its own (architecture §3b, "Wi-Fi blip").
